# neirolinks-docs

Публичный репозиторий исполнительной документации объектов NEIROLINKS.

## Публикация

- исходные страницы объектов хранятся в `objects/`;
- `scripts/build_all.py` проверяет комплектность и собирает отдельный Material for MkDocs сайт для каждого объекта;
- GitHub Actions публикует общий каталог `site/` в GitHub Pages;
- корневая страница сайта не содержит списка объектов;
- адрес каждого объекта содержит случайный идентификатор;
- для страниц установлен `noindex`.

## Ограничение

Репозиторий публичный. Запрещено добавлять пароли, токены, бэкапы контроллеров, закрытые конфиги, персональные данные и другие секреты.
