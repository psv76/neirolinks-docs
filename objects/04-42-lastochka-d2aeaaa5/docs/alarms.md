# Аварии и неисправности

1. Откройте Sprut.hub → **Котельная** → **Подпитка отопления**.
2. Посмотрите давление, причину аварии и причину запрета.
3. Проверьте, нет ли явных признаков протечки.
4. При повторяющемся падении давления, утечке, неисправности датчика или повторной блокировке обратитесь к специалисту.
5. Не сбрасывайте аварийную блокировку многократно. После сброса автоматический цикл может запуститься без ожидания.
