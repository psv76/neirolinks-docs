# Быстрый старт

1. Откройте Sprut.hub → **Котельная**.
2. Посмотрите плитку **«Давление отопления»**.
3. Откройте карточку **«Подпитка отопления»**, чтобы проверить состояние, причины аварии и запрета.
4. При уведомлении воспользуйтесь краткой памяткой.

**[Открыть мобильную инструкцию →](https://psv76.github.io/neirolinks-docs/o/04-42-lastochka-d2aeaaa5/guide/)**
