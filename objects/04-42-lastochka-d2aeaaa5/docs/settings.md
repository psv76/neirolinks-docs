# Что означают элементы Sprut

**Автоподпитка** — переключатель разрешения автоматического цикла.

**Давление отопления** — показание давления с поправкой, только для просмотра.

**Состояние** — текущая стадия работы.

**Аварийная блокировка** — сообщает о запрете дальнейших попыток.

**Причина аварии** — объясняет, из-за чего произошла блокировка.

**Причина запрета** — указывает, почему сейчас нельзя запускать подпитку.

**Датчик давления** — сообщает об исправности измерения.

**Низкое давление** — отдельный сигнал низкого давления.

**Авторежим WB** — информационный статус инженерного разрешения.

**Сбросить аварию** — кнопка очистки программной блокировки после устранения причины. При разрешённой автоматике может сразу начаться новая подпитка.
