# Подпитка отопления

На контроллере создано виртуальное устройство автоматической подпитки. Его основные параметры доступны в Sprut.hub.

- Старт при давлении не выше 1,0 бар после подтверждения условия.
- Цель — 1,2 бар после стабилизации давления.
- Клапан открывается короткими импульсами с проверкой давления между ними.
- При неисправности, чрезмерно частых циклах или недостижении цели автоматика блокирует дальнейшую подпитку.
