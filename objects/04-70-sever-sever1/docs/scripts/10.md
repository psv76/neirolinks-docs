# Коррекция температуры

`10_DeltaTemp.js`

## Назначение

Создаёт виртуальные устройства температурных зон, корректирует показания физических 1-Wire датчиков и предоставляет настройки, которые сценарий [20](20.md) использует для температурных уведомлений.

Сам сценарий 10 не подтверждает аварии и не отправляет Telegram.

## Виртуальные параметры

В каждой зоне создаются:

- `Delta` — поправка к физическому датчику;
- `Tizm` — скорректированная температура;
- `Tmax` — порог уведомления;
- `Hyst` — гистерезис восстановления;
- `DelayAlarmMin` — задержка температурной аварии;
- `DelayRestoreMin` — задержка восстановления;
- `Switchmsg` — статус **«Температура в норме»**.

## Основной алгоритм

Скорректированная температура:

`Tizm = sensor + Delta`

Результат округляется до 0,1 °C.

Пересчёт выполняется:

- при изменении физического датчика;
- при изменении `Delta`;
- примерно через 1 секунду после запуска сценария.

Запись в `Tizm` выполняется только при изменении рассчитанного значения.

## Межскриптовая связь

Сценарий [20](20.md) использует `Tizm`, `Tmax`, `Hyst`, `DelayAlarmMin`, `DelayRestoreMin` и `Switchmsg`.

Решение о подтверждённой аварии и восстановлении принимает [WBHelpers](helpers.md), вызванный сценарием 20.
