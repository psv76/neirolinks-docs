# Аварийные уведомления

`20_AlarmRules.js`

## Назначение

Контролирует аварийные и восстановительные состояния холодильных установок и температурных зон.

Сценарий не управляет компрессорами. Он описывает контролируемые физические входы, формирует тексты событий и передаёт обработку общему модулю [WBHelpers](helpers.md).

## Текущая задержка бинарных событий

`DEFAULT_DELAY_MS = 10000`, то есть **10 секунд**.

Одна и та же задержка сейчас передаётся для:

- RKS;
- HP;
- неисправности вентилятора кондиционера;
- отдельных аварийных входов воздухоохладителей;
- отсутствия питания / РНПП.

Если состояние исчезает раньше окончания задержки, сообщение не отправляется.

> На объекте наблюдались RKS-импульсы около 3 секунд. При текущей выдержке 10 секунд они не формируют Telegram. Это текущее поведение, а не ошибка документации; требуемая задержка вынесена на согласование.

## Группа причин компрессора

Для компрессора формируется список доступных причин:

- HP;
- RKS;
- неисправность вентилятора кондиционера, если вход задан.

Каждая причина подтверждается отдельно. Каждая подтверждённая причина может отправить собственное аварийное сообщение.

После исчезновения всех причин группы, если до этого хотя бы одна авария была доставлена, отправляется **«✅ Авария устранена»**.

## Питание / РНПП

Для контроля питания используется отдельный бинарный вход каждого компрессора.

Активной аварией считается отсутствие логической единицы на этом входе.

Сообщения:

- `🔴⚡ Нет напряжения`;
- `🟡⚡ Напряжение появилось`.

## Температура

Для каждой зоны в `WBHelpers.createTemperatureAlarm()` передаются:

- `Tizm`;
- `Tmax`;
- `Hyst`;
- `DelayAlarmMin`;
- `DelayRestoreMin`;
- `Switchmsg`.

Текст аварии содержит уставку и текущую температуру.

## Формат Telegram

Сообщение собирается блоками:

1. `Хладотерминал Север`;
2. зона;
3. пустая строка;
4. оборудование или `Температура`;
5. статус;
6. дополнительные строки при необходимости.

Пример структуры:

```text
Хладотерминал Север
Камера 4 МО6

Компрессор 2
🔴⚡ Нет напряжения
```

## Ограничения

- Сценарий оценивает электрические входные сигналы, а не внутреннее состояние холодильного контроллера.
- Telegram не заменяет штатные защиты холодильной установки.
- Сигнал короче текущей задержки является отфильтрованным событием и уведомление не вызывает.
