## Формулы

Скорректированная температура:

`Tizm = физический датчик + Delta`

Температурная авария:

`Tizm > Tmax`

Восстановление:

`Tizm <= Tmax - Hyst`

Изменение числового значения температуры внутри уже выполняющегося условия не сбрасывает выдержку.

## Доступность параметров

Пользователь может изменять:

- `Delta`;
- `Tmax`;
- `Hyst`;
- `DelayAlarmMin`;
- `DelayRestoreMin`.

`Tizm` и `Switchmsg` доступны только для чтения.
