# Аварии и неисправности

| Состояние | Автоматическое действие | Действие пользователя |
| --- | --- | --- |
| Газовый котёл не греет / ошибка / потеря OpenTherm | После подтверждения включается электрокотёл, газовый отключается, отправляется письмо. | Устранить причину, проверить физическое включение резерва, затем выполнить ручной сброс. |
| Перегрев подачи тёплого пола | При 50 °C клапан закрывается в 0 %. | Проверить насос, клапан и источник горячей подачи. |
| Перегрев радиаторного контура | При 80 °C клапан закрывается в 0 %. | Проверить насос, клапан и котёл. |
| Ошибка датчика подачи | Соответствующий смесительный клапан закрывается в 0 %. | Проверить датчик и связь. |
| Протечка | Отправляется письмо и запись в журнале. | Проверить место протечки и работу физического контроллера перекрытия. |
| Работа контроллера от батареи | Отправляется письмо. | Проверить вводное питание и резерв. |
| Высокий CO₂ / влажность | Отправляется письмо. | Проветрить помещение и проверить вентиляцию. |

> Важно. Журнал: события пишутся в системный журнал wb-rules.service . Команда в MQTT не является подтверждением физического срабатывания без обратной связи.
