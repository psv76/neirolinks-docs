# Центр уведомлений

Выберите, **о каких ситуациях система должна сообщать по email**. В интерфейсе ниже галочки, которые уже предусмотрены установленными скриптами на дату последнего аудита, отмечены автоматически. Новые правила помечены как «Требует внедрения».

<div id="notification-center">
  <p>Загрузка интерактивного реестра… Если интерфейс не появился, включите JavaScript и обновите страницу.</p>
</div>

!!! info "Как работает заявка"
    Изменения на этой странице **не управляют котлами, насосами, уставками или защитами**. Отправка формирует заявку на настройку уведомлений. Она вступает в силу только после проверки и применения инженером NEIROLINKS.

!!! warning "Подключение сервиса приёма заявок"
    Пока сервис приёма заявок не развёрнут, кнопка «Отправить изменения» честно сообщает об отсутствии сервера. Доступно **«Скачать JSON»** для ручной передачи инженеру. Автоматическая email-отправка с вложением требует отдельного HTTPS-сервиса — GitHub Pages сам этого не обеспечивает.

Подробнее о фактических температурах и ограничениях: [Параметры системы](settings.md). Инструкции при авариях: [Аварии и неисправности](alarms.md).
