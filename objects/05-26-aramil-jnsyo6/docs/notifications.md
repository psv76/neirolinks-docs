# Центр уведомлений

Для объекта **05 26 «Баня Арамиль»** уведомления разделены между двумя системами. Это согласованное 21.11.2026 решение без переноса комнатных термостатов из Sprut.hub в Wiren Board.

| Подсистема | Где настраивается | Способ |
|---|---|---|
| Комнатные термостаты: комната, бассейн, подвал, беседка | **Sprut.hub**, отдельно от этой формы | Push-уведомления |
| Котельная, обычная ГВС, вентиляция, протечки, электропитание и технические события WB | **Этот центр**, после проверки инженером | Email |
| Аварийные защиты, управление котлами, насосами и исполнительными механизмами | Только инженерная автоматика | Не изменяются этой формой |

## Комнатные термостаты — Sprut.hub

Рабочая логика комнатных термостатов находится в **Sprut.hub**. Для них не требуется передавать уставки в WB и не предусматривается email-заявка через этот центр.

Целевой сценарий: если измеренная температура помещения ниже **текущей уставки соответствующего термостата** на 5 °C в течение согласованной выдержки, Sprut.hub направляет push заказчику. При изменении уставки заказчиком сравнение должно автоматически использовать новое значение. Состояние «нагрев выключен» и восстановление температуры следует учесть отдельно при настройке сценария.

**Статус:** доступ к Sprut.hub отсутствует; сценарии push пока **не настроены и не испытаны**. Подтверждена лишь техническая возможность уведомлений в сценариях из [официальной документации Sprut.hub](https://wiki.spruthub.ru/Push_уведомления_из_webapp). После появления доступа нужно проверить четыре термостата, согласовать выдержку, настроить получателя и выполнить тестовую доставку на устройство заказчика. Перенос логики в WB отложен до отдельного решения заказчика.

## Email-уведомления инженерных систем

В интерфейсе ниже можно выбрать, **о каких событиях Wiren Board должны приходить email**. В каталоге **37 email-правил**, без комнатных термостатов. Галочки существующих уведомлений основаны на проверенных скриптах, новые правила отмечены как требующие внедрения.

<div id="notification-center">
  <p>Загрузка интерактивного реестра… Если интерфейс не появился, включите JavaScript и обновите страницу.</p>
</div>

!!! info "Как работает заявка"
    Настройки на этой странице **не управляют котлами, насосами, уставками или защитами**. Изменение формирует инженерную заявку в формате JSON. Она вступает в силу только после проверки и отдельного внедрения NEIROLINKS. Старые JSON-файлы с комнатными правилами отклоняются по версии каталога.

!!! warning "Подключение сервиса приёма заявок"
    Пока HTTPS-сервис приёма заявок не развёрнут, кнопка «Отправить изменения» сообщает об отсутствии сервера. Доступно **«Скачать JSON»** для ручной передачи инженеру. Автоматическая отправка JSON-вложения по email требует отдельного сервера; GitHub Pages самостоятельно письма не отправляет.
