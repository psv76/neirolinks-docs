# Управление газовым котлом

`01 Управление уставкой газового котла.js`

## Назначение

Собирает запросы на тепло от радиаторов, тёплого пола, бассейна, ГВС и вентиляции, выбирает активный профиль и передаёт газовому котлу уставку через OpenTherm.

## Входные данные

- запросы радиаторов и тёплого пола по состоянию сервоприводов
- запрос бассейна
- состояние насоса бойлера ГВС
- режим вентиляционной установки
- аварийный флаг котельной
- активность антилегионеллы

## Управляемые выходы

- wbe2-i-opentherm\_11/Heating Setpoint
- wbe2-i-opentherm\_11/Auto Temp Switch

## Основной алгоритм

- При активной аварии газовый котёл отключается уставкой 0 °C.
- При антилегионелле используется отдельный приоритетный профиль 80 °C.
- При запросах тепла выбирается профиль по сочетанию потребителей.
- Без запросов сохраняется уставка 50 °C и включается автоматический температурный режим котла.

## Уставки и таймеры

- Набор уставок одиночных и комбинированных профилей; диапазон ползунков 0–90 °C.
- Стартовая синхронизация через 2 секунды.

## Поведение после запуска

Через 2 секунды синхронизирует запросы и передаёт рассчитанное состояние котлу.

## Ограничения

- Единственный скрипт комплекта, который пишет уставку и Auto Temp Switch газового котла.
