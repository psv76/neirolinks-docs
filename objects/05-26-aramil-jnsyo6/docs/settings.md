# Параметры системы

Это **инженерный справочник**, а не форма изменения отопления. Уведомления настраиваются отдельно: [Центр уведомлений](notifications.md).

!!! warning "Источники и актуальность"
    Ниже совмещены документированные значения кода и отдельный **разовый read-only MQTT-снимок 19.11.2026 04:28 UTC**. Значения могут меняться на контроллере. Для внесения инженерных изменений требуется новый live-аудит, проверка и отдельное согласование.
