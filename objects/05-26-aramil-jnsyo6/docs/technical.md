## Межскриптовые связи

| Связь | Смысл |
| --- | --- |
| 01 → 03 | 01 формирует виртуальные запросы потребителей; 03 использует их для решения о резерве. |
| 03 → 01 | 03 устанавливает boiler\_room\_alarm/alarm; 01 отключает газовый котёл при активной аварии. |
| 04 → 11 | 04 управляет насосом радиаторов; 11 использует состояние насоса для разрешения регулирования клапана. |
| 05 → 10 | 05 управляет насосом тёплого пола; 10 использует состояние насоса для разрешения регулирования клапана. |
| 12 → 01 | 12 устанавливает anti\_legionella\_control/active; 01 выбирает профиль котла 80 °C. |
| 12 → 03 | 12 прекращает цикл при активном аварийном резерве; 03 не обслуживает ГВС и антилегионеллу. |

## Уведомления

Скрипты с уведомлениями используют настроенный на контроллере адрес получателя и префикс объекта в теме письма.

## Неясности, требующие проверки

- Назначения входов `input_1`, `input_2`, `input_5`, `input_4` контроллера протечек.
- Калибровка фиксированной коррекции +4 °C для обоих датчиков подачи.
- Интерпретация состояний WB-UPS для установленной прошивки.
- Часовой пояс контроллера для расписания 06:00–08:00.
- Физическое выполнение команд котлам, контактору, насосам и клапанам.
